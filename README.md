# 🎲 모두의 자리뽑기 (Modu-seatsPick)

구글 스프레드시트를 데이터베이스(DB)로 사용하는 교사용 자리배치 및 룰렛 자리뽑기 시스템입니다. 
이제 깃허브(GitHub Pages) 등을 통해 손쉽게 호스팅하여 사용할 수 있습니다.

---

## 🚀 빠른 시작 가이드 (배포 및 연동 방법)

본 시스템은 **프론트엔드(GitHub Pages)**와 **백엔드(Google Apps Script - API)**로 분리되어 작동합니다. 
스프레드시트를 생성하고 구글 앱스 스크립트를 웹앱으로 배포한 뒤, URL을 등록하여 사용해야 합니다.

### 1단계. 구글 스프레드시트 및 백엔드(GAS) 설정
1. 새로운 [구글 스프레드시트](https://sheets.google.com)를 생성합니다.
2. 스프레드시트 상단 메뉴에서 **확장 프로그램 > Apps Script**를 클릭합니다.
3. 기존 코드를 모두 지우고, 본 저장소의 `code.gs` 파일 내용을 그대로 복사하여 붙여넣습니다.
4. 상단의 **저장(디스크 아이콘)**을 누릅니다.

### 2단계. 구글 앱스 스크립트 웹앱(Web App) 배포
1. Apps Script 화면 우측 상단의 **배포 > 새 배포**를 클릭합니다.
2. 유형 선택(톱니바퀴 아이콘)에서 **웹앱(Web App)**을 선택합니다.
3. 설정을 다음과 같이 구성합니다:
   - **설명:** `자리뽑기 API` (원하는 설명 입력)
   - **웹앱 실행 사용자:** `나(본인 구글 계정)`
   - **액세스 권한이 있는 사용자:** `모든 사람(Anyone)` (외부 통신을 위해 필수)
4. **배포** 버튼을 누릅니다.
5. 승인 요청 팝업이 뜨면 **권한 검토**를 누르고 본인의 구글 계정을 선택한 후, **Advanced(고급) > Go to Untitled project(unsafe)**를 클릭하여 권한을 허용합니다.
6. 배포가 완료되면 생성된 **웹앱 URL**을 복사해 둡니다.
   - *예시: `https://script.google.com/macros/s/XXXXXX/exec`*

### 3단계. 깃허브 배포 (GitHub Pages)
1. 본 저장소(`https://github.com/semyo0513/Modu-seatsPick`)를 Fork하거나 Clone합니다.
2. GitHub 저장소의 **Settings > Pages** 메뉴로 이동합니다.
3. **Build and deployment > Source**를 `Deploy from a branch`로 설정하고, Branch를 `main` (또는 `master`) / `/root`로 설정한 후 **Save**를 누릅니다.
4. 약 1~2분 뒤 배포된 사이트 URL(예: `https://사용자이름.github.io/Modu-seatsPick`)이 생성됩니다.

### 4단계. 웹앱 연동 및 사용
1. 배포된 깃허브 페이지 주소로 접속합니다.
2. 처음 접속 시 또는 로그인 창 하단에 있는 **⚙️ 백엔드(GAS) API URL 설정**을 클릭합니다.
3. 2단계에서 복사해 둔 **구글 앱스 스크립트 웹앱 URL**을 입력하고 **설정 저장**을 누릅니다.
4. 이제 회원가입 및 로그인을 통해 학생 정보 저장, 좌석 배치 설계, 규칙 설정, 히스토리 조회 등의 모든 기능을 사용할 수 있습니다!

## 📂 백엔드 시트(DB) 구조 안내
웹앱을 통해 최초로 데이터 통신(로그인/회원가입 등)이 발생하면 구글 스프레드시트에 아래 시트들이 자동으로 생성됩니다. 수동으로 시트를 만들지 않으셔도 됩니다.

- **회원목록:** 교사 계정 정보 (이메일, 해시된 비밀번호 등)
- **학생목록:** 교사 계정별 학생 명단 (번호, 이름, 제외 여부 등)
- **자리배치:** 저장된 최종 자리 배치 정보 (JSON 포맷)
- **배치기록:** 역대 배치 이력 로그
- **규칙설정:** 짝꿍 지정 또는 분리 등 적용 규칙
- **설정:** 교실 레이아웃(행/열 수 등) 정보

## 🛠️ 문제 해결 (Troubleshooting)
* **Q. 로그인이 안 되거나 무한 로딩이 발생합니다.**
  * 구글 앱스 스크립트를 배포할 때 **액세스 권한이 있는 사용자**를 반드시 **모든 사람(Anyone)**으로 설정했는지 확인해 주세요. `나만(Only me)`으로 되어 있을 경우 외부 웹앱(GitHub)에서 시트에 접근할 수 없습니다.
* **Q. 구글 앱스 스크립트 코드를 변경했는데 적용이 안 됩니다.**
  * 코드를 변경한 경우 반드시 **배포 > 배포 관리**에서 기존 배포 버전을 편집하여 **새 버전**으로 업데이트하거나, **새 배포**를 수행하고 변경된 새 URL을 웹앱에 다시 등록해야 합니다.
